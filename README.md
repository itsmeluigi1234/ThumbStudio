## About

ThumbStudio is an Android app project focused on making Roblox-inspired thumbnail creation accessible from a mobile device.

The goal is to bring thumbnail editing, 3D scene creation, and AI-assisted creative tools into one convenient workspace.

> **Project status:** Early development. Features listed below may be planned rather than currently available.

## Features

- **Thumbnail Editor** — Create and refine gaming thumbnails.
- **3D Studio** — Work toward building and posing 3D scenes.
- **AI Creative Tools** — Explore AI-assisted image and design workflows.
- **Android First** — Develop and build with mobile users in mind.
- **Automated Builds** — Use GitHub Actions to build Android APKs in the cloud.

## Building the App

The Android build workflow is provided in `.github/workflows/android-build.yml`.

Once the Android Gradle project and Gradle wrapper are added, GitHub Actions can build the debug APK and publish it as a downloadable workflow artifact.

For local development, you will need:

- Android SDK
- A compatible JDK
- Gradle wrapper files from the project

**Note:** The application is still being established. Build instructions will be expanded as the project structure is finalized.
